# Последний причал

Играбельный срез метроидвании на **чистом JavaScript и Canvas 2D**: Нижний причал → Вокзал → Рабочие кварталы. 20 комнат, воздушный рывок, зацеп и прыжки от стен, два сокращения, подъёмник, три места отдыха, два обычных врага и смотритель двора.

Никаких фреймворков, игровых движков, внешних ресурсов или зависимостей для запуска. Изображение рисуется процедурно; звуки синтезируются Web Audio. Игра и весь интерфейс — на русском.

## Запуск

Нужен **Node.js 22+** (в cloud установлен Node 24).

```sh
cd /workspace/Metroid
npm run dev
```

Сервер слушает порт **3000**. Откройте его в браузере. `npm install` не требуется. Для другого порта: `PORT=8080 npm run dev`. Двойной щелчок по `index.html` не подходит: модули и JSON загружаются через HTTP.

```sh
npm run validate  # ссылки, уникальные ID, контракт и безопасные точки появления
npm test          # контроллер, геометрия, бой, сохранения, прогрессия, ввод
npm run metrics   # измеренные H, J, JD, T; artifacts/metrics.json
npm run build     # автономная статическая сборка dist/
npm run preview   # запустить dist/ на том же порту
```

`dist/` можно разместить на статическом HTTP-хостинге в корне сайта или подпапке, включая GitHub Pages. Сборка закрывает доступ к отладочному API и пульту.

## Управление

| Действие | Клавиатура | Стандартный геймпад |
|---|---|---|
| Движение | A / D, ← / → | Левый стик / крестовина |
| Прыжок | Space / Z; удержание меняет высоту | A |
| Удар | J / X | X |
| Воздушный рывок | Shift / K | B |
| Взаимодействие | E | Y |
| Прыжок от стены | Держать направление к стене + Space | К стене + A |
| Спуск через тонкую платформу | ↓ + Space | Вниз + A |
| Карта | M; колесо и перетаскивание | View |
| Пауза | Esc | Start |

На телефоне движение управляется **свайпом и удержанием**: проведите влево/вправо по левой половине игрового поля или зоне под большим пальцем. Отпустите палец, чтобы остановиться; для разворота проведите в другую сторону от начала жеста. Прыжок, рывок, удар и действие остаются кнопками справа. Для спуска через платформу удерживайте ↓ и нажмите ↑. Экран поддерживает несколько пальцев одновременно, безопасные отступы и смену ориентации. В портретном режиме камера приближает героя и следует за ним; физика прыжка не меняется. На карте золотой прицел отмечает текущую цель, включая ещё не посещённый «Дом без лестниц». Подпись указывает ближайший открытый переход; маршрут учитывает лифт и сокращения. Просмотр цели не отмечает комнату посещённой. Короткие подсказки написаны прямо на лицевых сторонах настилов и платформ; они меняют обозначения под устройство и не перекрывают героя. Потеря фокуса, сворачивание или отключение геймпада ставят игру на паузу и сбрасывают удерживаемый ввод.

## Путешествие

Начните на пристани, найдите **Порыв ветра в P04**, прыгните с рывком через разорванный мост P05. В P07 поднимите знакомую решётку, а в P08 запустите подъёмник. На вокзале безопасно; мастерская необязательна. В городе найдите **Медные когти в R04**, освоитесь в шахте R05 и поднимитесь на крыши. После боя в R07 опустите пожарную лестницу и отдельно включите мост. Башня R08 завершает срез и оставляет исследование доступным.

Осколки: нижняя часть P03, верхние мостки P06 и часовщик V03. Сердце города в верхней нише P03 требует позднего возврата с зацепом и увеличивает здоровье. Затопленный тоннель и дверь Архива обещают будущие ветви; они намеренно не открываются в этом срезе.

Прогресс записывается при событиях и раз в 30 секунд. После перезапуска или смерти герой возвращается к **последнему месту отдыха**, сохраняя способности, находки, открытые проходы и карту. Хранилище привязано к origin браузера: смена порта или браузера создаёт отдельное сохранение. Имеются версия, контрольная сумма, атомарная замена записи и предыдущая исправная копия. Ошибки хранилища видны в интерфейсе.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `data/physics.json` | Скорости, ускорение, окно прыжка, буфер, рывок, зацеп, бой |
| `data/world.json` | 20 комнат, их геометрия, выходы, точки появления, условия, сущности, отдельная LAB |
| `src/input.js` | Клавиатура, стандартный геймпад, сенсорный ввод → действия |
| `src/physics.js` | Чистый контроллер и коллизии; фиксированный шаг 1/120 с |
| `src/game.js` | Загрузка комнат, взаимодействия, переходы, бой и возврат |
| `src/enemies.js` | Дозорный, подвесной паразит, две атаки смотрителя |
| `src/save.js` | Постоянный прогресс отдельно от текущего боя |
| `src/render.js` | Оформление, анимация, камера, эффекты; не влияет на коллизии |
| `src/map.js` | Посещённые комнаты, замеченные проходы, отдых, сокращения, масштаб |
| `src/audio.js` | Синтез звуков и фонового окружения |
| `src/main.js` | Инициализация, цикл, меню и доступность |

Длину рывка, выход и условие двери можно изменить в JSON без изменения логики. Условия: `flag`, `and`, `or`, `not`, `atLeast`, `local`. Изменение имени комнаты сохраняет `roomId`; состояния мира используют стабильные ID.

## Инструменты и проверка

В dev-сервере добавьте `?debug=1` и нажмите **`** (клавиша под Esc). Пульт позволяет запускать любую комнату, включая измерительную **LAB**, выдавать/удалять способности, включать полёт и неуязвимость, смотреть коллайдеры, триггеры, точки появления, контакты, флаги, FPS и худшее время кадра. «Сбросить комнату» сбрасывает текущий бой, сохраняя постоянные изменения. Отладка требует явного параметра и loopback-хоста; в production-сборке не включается.

Браузерная проверка использует Python Playwright и системный Chromium (в подготовленном cloud уже есть):

```sh
npm run test:browser
```

Скрипт сам поднимает сервер, если порт свободен. Для другого браузера задайте `CHROMIUM_PATH`, для работающего сервера — `BASE_URL`. Проходит все комнаты через реальные взаимодействия, проверяет рывок клавиатурой, бой, оба сокращения, лифт с паузой, возврат за секретом, смерть и перезапуск. Для ускорения перемещения к объектам используются тестовые позиции; это не непрерывное ручное прохождение. Физическая проходимость учебных участков отдельно проверяется реальным контроллером в Node-тестах. Скриншоты и результаты находятся в `artifacts/` и не входят в git.

Цель прототипа — современный desktop-браузер, экран от **1280×720**, **60 FPS** при физике 120 Гц. Размер окна не меняет физические метрики. На телефонах игровое поле и камера меняют видимую область без изменения физических параметров; HUD и кнопки занимают отдельные зоны. Реальная проверка на минимальном мобильном устройстве остаётся отдельной задачей.

Исходное задание: [docs/SPEC.ru.md](docs/SPEC.ru.md). Границы реализации и дальнейшие этапы: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет и публикует `dist/` после каждого push в `main`. Ожидаемый адрес: `https://gdrclm.github.io/Metroid/`. В Settings → Pages источник должен быть **GitHub Actions**. Если автоматическое включение Pages недоступно токену workflow, выберите этот источник один раз и перезапустите workflow. Репозиторий не нужно делать публичным автоматически: для приватного репозитория доступность Pages зависит от тарифа владельца.

Проверка мобильного ввода в Chromium: `npm run test:mobile` при запущенном dev-сервере. Скрипт проверяет 320×568, 390×844, 844×390, свайпы с удержанием и разворотом, прыжок вторым пальцем через CDP, остановку после отпускания/отмены, поворот экрана и маркер квеста до посещения целевой комнаты.
