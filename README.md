# Последний причал

Играбельный срез метроидвании на **чистом JavaScript и Canvas 2D**: Нижний причал → Вокзал → Рабочие кварталы. 22 комнаты, воздушный рывок, зацеп и прыжки от стен, два сокращения, два необязательных обхода, подъёмник, три места отдыха, два обычных врага и смотритель двора.

Никаких фреймворков, игровых движков, внешних ресурсов или зависимостей для запуска. Изображение рисуется процедурно; звуки синтезируются Web Audio. Игра и весь интерфейс — на русском.

## Запуск

Нужен **Node.js 22+** (в cloud установлен Node 24).

```sh
cd /workspace/Metroid
npm run dev
```

Сервер слушает порт **3000**. Откройте его в браузере. `npm install` не требуется. Для другого порта: `PORT=8080 npm run dev`. Двойной щелчок по `index.html` не подходит: модули и JSON загружаются через HTTP.

```sh
npm run validate  # ссылки, уникальные ID, контракт и безопасные точки появления
npm test          # контроллер, геометрия, бой, сохранения, прогрессия, ввод
npm run metrics   # измеренные H, J, JD, T; artifacts/metrics.json
npm run build     # автономная статическая сборка dist/
npm run preview   # запустить dist/ на том же порту
```

`dist/` можно разместить на статическом HTTP-хостинге в корне сайта или подпапке, включая GitHub Pages. Сборка закрывает доступ к отладочному API и пульту.

## Управление

| Действие | Клавиатура | Стандартный геймпад |
|---|---|---|
| Движение | A / D, ← / → | Левый стик / крестовина |
| Прыжок | Space / Z; удержание меняет высоту | A |
| Удар | J / X | X |
| Воздушный рывок | Shift / K | B |
| Взаимодействие | E | Y |
| Лестница / осмотреть верх или низ | W / S, ↑ / ↓ | Вертикальная ось / крестовина |
| Прыжок от стены | Держать направление к стене + Space | К стене + A |
| Спуск через тонкую платформу | ↓ + Space | Вниз + A |
| Карта | M; колесо и перетаскивание | View |
| Пауза | Esc | Start |

На телефоне движение управляется **кнопками ← / →**. У видимой стрелки 52 px область нажатия 72×72 px — можно немного промахнуться за её край. У остальных игровых кнопок добавлено по 5 px вокруг. Удерживайте направление и нажимайте прыжок вторым пальцем; отпускание или отмена касания останавливает движение. Свайпы по игровому полю отключены. Прыжок, рывок, удар и действие остаются справа. Для спуска через тонкую платформу удерживайте ↓ и нажмите кнопку прыжка. Отдельные ↑/↓ служат для лестниц и осмотра. Открытые улицы пересекаются движением, двери и лифт — действием. Экран поддерживает несколько пальцев одновременно, безопасные отступы и смену ориентации. В портретном режиме камера приближает героя и следует за ним; физика прыжка не меняется. На карте золотой прицел отмечает текущую цель, включая ещё не посещённый «Дом без лестниц». Подпись указывает ближайший открытый переход; маршрут учитывает лифт и сокращения. Просмотр цели не отмечает комнату посещённой. На карте доступны четыре сохраняемые отметки: вернуться, секрет, опасность, непонятно; выберите тип и коснитесь комнаты. Кнопка «Герой» центрирует карту на текущей комнате. Короткие подсказки исчезают после освоения действия и написаны прямо на лицевых сторонах настилов и платформ; они меняют обозначения под устройство и не перекрывают героя. Потеря фокуса, сворачивание или отключение геймпада ставят игру на паузу и сбрасывают удерживаемый ввод.

## Путешествие

Начните на пристани, найдите **Порыв ветра в P04**, прыгните с рывком через разорванный мост P05. В P07 поднимите знакомую решётку, а в P08 запустите подъёмник. На вокзале безопасно; мастерская необязательна. В городе найдите **Медные когти в R04**, освоитесь в шахте R05 и поднимитесь на крыши. После боя в R07 опустите пожарную лестницу и отдельно включите мост. Башня R08 завершает срез и оставляет исследование доступным.

Осколки: нижняя часть P03, новая галерея цепей P09 над P06 и часовщик V03 после ремонта маховика. За три осколка часовщик даёт золотую нить для шарфа и подсказку. Нижняя арка R09 связывает безопасный низ крыш с двором башни. Сердце города в верхней нише P03 требует позднего возврата с зацепом и увеличивает здоровье. Затопленный тоннель и дверь Архива обещают будущие ветви; они намеренно не открываются в этом срезе.

Прогресс записывается при событиях и раз в 30 секунд. После перезапуска или смерти герой возвращается к **последнему месту отдыха**; перед смотрителем действует отдельная точка повтора у лампы, сохраняя способности, находки, открытые проходы и карту. Обычные враги остаются побеждёнными до отдыха или смерти. Старые сохранения получают новые поля без сброса находок. Хранилище привязано к origin браузера: смена порта или браузера создаёт отдельное сохранение. Имеются версия, контрольная сумма, атомарная замена записи и предыдущая исправная копия. Ошибки хранилища видны в интерфейсе.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `data/physics.json` | Скорости, ускорение, окно прыжка, буфер, рывок, зацеп, бой |
| `data/world.json` | 22 комнаты, локальная геометрия, схема карты, выходы, механизмы и LAB |
| `src/input.js` | Клавиатура, стандартный геймпад, сенсорный ввод → действия |
| `src/physics.js` | Чистый контроллер и коллизии; фиксированный шаг 1/120 с |
| `src/game.js` | Загрузка комнат, взаимодействия, переходы, бой и возврат |
| `src/enemies.js` | Дозорный, подвесной паразит, две атаки смотрителя |
| `src/save.js` | Постоянный прогресс отдельно от текущего боя |
| `src/render.js` | Оформление, анимация, камера, эффекты; не влияет на коллизии |
| `src/map.js` | Посещённые комнаты, замеченные проходы, отдых, сокращения, масштаб |
| `src/audio.js`, `src/music.js` | Четыре канала, локальные источники, акустика, непрерывная музыка фортепиано и скрипки, боевая тема |
| `src/atmosphere.js`, `src/particles.js`, `src/atmosphere-render.js` | Сохраняемые сцены, общий ветер, эмиттеры и фоновые занятия жителей |
| `src/camera.js`, `src/safety.js` | Профили камеры, доступность взаимодействий и безопасный возврат |
| `src/editor.js`, `src/telemetry.js` | Редактор комнат и статистика плейтеста |
| `src/main.js` | Инициализация, цикл, меню и доступность |

Длину рывка, выход и условие двери можно изменить в JSON без изменения логики. Условия: `flag`, `and`, `or`, `not`, `atLeast`, `local`. Изменение имени комнаты сохраняет `roomId`; состояния мира используют стабильные ID.

## Инструменты и проверка

В dev-сервере добавьте `?debug=1` и нажмите **`** (клавиша под Esc). Пульт позволяет запускать любую комнату, включая измерительную **LAB**, выдавать/удалять способности, включать полёт и неуязвимость, смотреть коллайдеры, триггеры, точки появления, контакты, флаги, FPS и худшее время кадра. «Сбросить комнату» сбрасывает текущий бой, сохраняя постоянные изменения. Отладка требует явного параметра и loopback-хоста; в production-сборке не включается.

Браузерная проверка использует Python Playwright и системный Chromium (в подготовленном cloud уже есть):

```sh
npm run test:browser
npm run test:mobile
npm run test:editor
npm run test:atmosphere
npm run test:audio
npm run test:continuous
npm run test:journey
npm run metrics:shortcuts
```

`test:browser` сам поднимает сервер, если порт свободен; для остальных браузерных сценариев сначала запустите `npm run dev`. Для работающего сервера можно задать `BASE_URL`. Интеграционный сценарий использует подготовленные позиции; отдельный `test:journey` проходит все 22 комнаты реальными событиями клавиатуры, получает способности, побеждает босса и возвращается за сердцем без телепортаций и неуязвимости. Это автоматический маршрут, а не слепой плейтест нового человека. Скриншоты и результаты находятся в `artifacts/` и не входят в git.

Редактор: `?debug=1` → **`** → «Редактор комнаты». Можно перетаскивать коллайдеры, предметы, выходы и точки появления, менять размер платформ, условия JSON и принимающий выход. Пунктир показывает траектории настоящего контроллера. Доступны отмена, локальный черновик и импорт/экспорт комнаты либо мира с существующими ID. Для переноса изменений в исходники экспортируйте JSON; редактор не записывает файлы репозитория. «Экспорт плейтеста» выгружает время по комнатам, падения, смерти и причины, закрытые выходы, сокращения и возврат к секрету.

Цель прототипа — современный desktop-браузер, экран от **1280×720**, **60 FPS** при физике 120 Гц. Размер окна не меняет физические метрики. На телефонах игровое поле и камера меняют видимую область без изменения физических параметров; HUD и кнопки занимают отдельные зоны. Реальная проверка на минимальном мобильном устройстве остаётся отдельной задачей.

Исходное задание: [docs/SPEC.ru.md](docs/SPEC.ru.md). Границы реализации и дальнейшие этапы: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет и публикует `dist/` после каждого push в `main`. Ожидаемый адрес: `https://gdrclm.github.io/Metroid/`. В Settings → Pages источник должен быть **GitHub Actions**. Если автоматическое включение Pages недоступно токену workflow, выберите этот источник один раз и перезапустите workflow. Репозиторий не нужно делать публичным автоматически: для приватного репозитория доступность Pages зависит от тарифа владельца.

Проверка мобильного ввода в Chromium: `npm run test:mobile` при запущенном dev-сервере. Скрипт проверяет 320×568, 390×844, 844×390, кнопки направлений с расширенными областями нажатия, прыжок вторым пальцем через CDP, остановку после отпускания/отмены, поворот экрана и маркер квеста до посещения целевой комнаты.


## Атмосфера города

Уход лодки в P01, гостеприимство в P02, первый подъём P08→V01 и открытие пожарной лестницы R07→R02 связывают звук, частицы и изменения быта. При выходе, смерти или перезагрузке сохраняется итог сцены; её разовые звуки и выбросы не повторяются. Управление остаётся доступно, кроме обычного короткого перехода кабины.

В настройках «Баланс звука» отдельно регулирует музыку, окружение, действия и интерфейс. «Частицы → Меньше» уменьшает декор, сохраняя игровые сигналы. Уменьшение вспышек смягчает яркость эффектов.

Музыка фортепиано и скрипки непрерывно развивается по четырёхтактовой гармонии; у Причала, Вокзала и Кварталов разные темп и тема. В бою со смотрителем включается напряжённая тема на 144 BPM с быстрым фортепиано, короткими смычковыми акцентами и низким пульсом. Предупреждения атак остаются слышны поверх музыки. Выпад смотрителя наносит урон только при соприкосновении тел в активной фазе; подготовка, восстановление и прыжок рядом безопасны. Волна наносит урон при касании видимого снаряда.

В dev-пульте доступны радиусы локального звука, области эмиттеров, карточка истории комнаты и просмотр «До события / После события». Просмотр не меняет сохранение. Данные и критерии проверки: [docs/ATMOSPHERE.md](docs/ATMOSPHERE.md).
