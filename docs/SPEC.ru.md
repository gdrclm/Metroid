Ниже — технический чек-лист для всей игры и подробный макет **первого игрового среза: Нижний причал → Вокзал → часть Рабочих кварталов**.

Срез включает **20 комнат, две способности, два крупных сокращения пути, безопасный хаб, небольшой бой и несколько секретов**. Его задача — проверить основной цикл метроидвании: увидеть препятствие → найти обход → получить способность → освоить её → открыть короткий путь → вернуться в знакомое место с новыми возможностями.

Обозначения приоритетов:

- **P0** — обязательно для рабочего среза.
- **P1** — обязательно до массового производства большой карты.
- **P2** — расширение после проверки основного цикла.

Все размеры и времена ниже — **стартовые параметры для прототипа**, а не окончательный баланс.

**7. Метрики геометрии**

Сначала измеряется реальный контроллер. Затем под него строится карта.

Обозначения:

- `H` — максимальная высота обычного прыжка.
- `J` — дальность обычного прыжка между площадками одной высоты.
- `JD` — дальность прыжка с воздушным рывком.
- `W` — ширина коллайдера героя.
- `T` — время полного прыжка.

- [ ] **P0** Создать отдельную тестовую комнату для измерения `H`, `J`, `JD`, `T`.
- [ ] **P0** Измерить показатели с места и с разбега.
- [ ] **P0** Измерить прыжки на площадку выше и ниже стартовой.

- [ ] **P0** Зафиксировать минимальную ширину шахты для прыжков от стен.
- [ ] **P0** Обязательные ранние прыжки имеют запас относительно предельной дальности.
- [ ] **P0** Препятствие для рывка превышает обычную дальность с учётом всех разрешённых способов движения.
- [ ] **P0** Препятствие для рывка уверенно преодолевается после получения способности.
- [ ] **P0** Высотный барьер для зацепа нельзя случайно пройти обычным прыжком.
- [ ] **P0** Камера позволяет увидеть площадку приземления до обязательного прыжка.
- [ ] **P1** Дизайнер видит предполагаемые траектории в редакторе.
- [ ] **P1** Пересчёт параметров движения помечает зависимые испытания для повторной проверки.

**Важно:** ширина разрыва сама по себе не гарантирует блокировку. Более высокая стартовая площадка или падение с крыши могут увеличить дальность перелёта.

**26. Макет среза**

Общая география:

- Причал находится внизу слева.

- Рабочие кварталы тянутся вправо и вверх от Вокзала.

- Между регионами в этом срезе используются две основные связи: подъёмник и городской проход.

Обозначения:

```text
[P01]  room ID
----   horizontal connection
 |     vertical connection
 >>>   one-way travel
 /D/   dash required
 /W/   wall grip required
 [S]   rest point
 [A]   ability pickup
 [E]   combat encounter
 [X]   shortcut opened from far side
 [F]   future route, outside this slice
```

Схемы показывают пространственную организацию и связи. Точная форма платформ задаётся в макетах отдельных комнат.

**27. Нижний причал — 8 комнат**

```text
                    UPPER WALKWAYS

 [P07:X]------[P06]------[P05]
    |            |         ^
    |            |         |
    |            |        /D/
    |            |         |
    v            |         |
 [P02:S]------[P03]------[P04:A]
    |
 [P01]


                  CENTRAL LIFT

               [P06]
                  |
               [P08]
                  |
                  ^
                  |
               [V01]
```

В этой схеме связь `P06–P03` **не предусмотрена**: они находятся на разных высотах, а вертикальная линия от `P06` обозначает спуск к `P08`, вынесенный во второй фрагмент для читаемости. Полный список фактических выходов приведён ниже.

**Основной маршрут:**

```text
P01 -> P02 -> P03 -> P04
                      |
                 get DASH
                      |
                      v
P02 <- P07 <- P06 <- P05
              |
              v
             P08 -> V01
```

В `P07` игрок открывает проход в `P02`. После этого связь работает в обе стороны.

| Комната | Назначение | Основное содержание |
|---|---|---|
| `P01` | Вход | Безопасная пристань, движение и первый прыжок |
| `P02` | Опорная точка | Дом смотрителя, отдых, видимая закрытая решётка |
| `P03` | Исследование | Склад, первый враг, нижний секрет |
| `P04` | Способность | Крановая площадка, получение рывка |
| `P05` | Обучение | Применение рывка над безопасной страховочной площадкой |
| `P06` | Сочетание | Рывок, простые платформы, знакомый тип врага |
| `P07` | Сокращение | Открытие решётки в `P02` с дальней стороны |
| `P08` | Переход | Механизм и кабина подъёмника |

**Технические условия:**

- [ ] `P04→P05` нельзя пройти без рывка обычным способом.
- [ ] В `P05` ошибка не требует загрузки контрольной точки.
- [ ] `P06→P07` доступен до отправления на Вокзал.
- [ ] Решётка `P07↔P02` сохраняет открытое состояние.
- [ ] Из `P06` виден отдельный спуск к `P08`.
- [ ] Лифт можно вызвать с обеих сторон.
- [ ] После получения зацепа в `P03` становится доступна верхняя ниша.
- [ ] Подводное окно в `P01` остаётся обещанием будущей ветви.

- [ ] Подсказка повторяется только при необходимости.

**35. Проверка возврата в начало**

После получения зацепа игрок должен иметь удобный маршрут к старому секрету:

```text
R07
 |
 v
R02 -> R01 -> V04 -> V02 -> V01
                              |
                              v
P03 <- P02 <- P07 <- P06 <- P08
```

В `P03` он поднимается в ранее недоступную нишу.

Это проверяет сразу несколько систем:

- [ ] Сокращения действительно экономят время.
- [ ] Лифт работает в обратную сторону.
- [ ] Врагами не перегружен знакомый маршрут.
- [ ] Карта помогает вспомнить препятствие.
- [ ] Новая способность применяется вне учебной комнаты.
- [ ] Награда оправдывает возвращение.
- [ ] После получения награды можно быстро вернуться в Рабочие кварталы.
