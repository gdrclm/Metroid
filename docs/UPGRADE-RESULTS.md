# Результат аудита P0/P1

Отчёт версии `3deae2c`. Следующее обновление добавляет атмосферные сцены и возвращает мобильные кнопки по новому запросу: [ATMOSPHERE.md](ATMOSPHERE.md).

Реализованы пункты 1–49 из [исходного запроса](UPGRADE-REQUEST.ru.md). Пункт 50 требует физического телефона и остаётся ручной приёмкой: в cloud доступна только эмуляция Chromium. Автоматический маршрут не заменяет слепой плейтест новым человеком.

## Надёжность и география

| № | Изменение и проверка |
|---|---|
| 1 | Спуск только через фактическую одностороннюю опору, без проваливания в твёрдый пол; регрессии на краю, движущейся и нескольких тонких платформах. |
| 2 | Возврат на статичную опору с проверкой свободного тела, края, опасности и врагов; история предыдущих точек и запасной поиск. |
| 3 | Отдельные зоны взаимодействия и геометрическая видимость для двери, предмета, рычага, NPC; повторная проверка при нажатии. |
| 4 | Контекстный `lockedReason`: способность, смотритель, механизм, другая сторона. |
| 5 | Луч между центрами врага и героя; перекрытия блокируют обнаружение. |
| 6 | Верхние маршруты отражены по горизонтали; стороны выходов согласованы со схемой; непрямые лестницы обозначены явно. |
| 7 | Локальные физические границы отделены от схемы `mapShape`; валидатор запрещает случайные перекрытия и неверные размеры. |
| 8 | Улица — движение, дверь — E, лестница — вверх/вниз, лифт — E; ограниченное сохранение скорости только у улицы. |
