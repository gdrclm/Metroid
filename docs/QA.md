# Результаты проверки

Проверено 7 ноября 2026 в cloud Linux: Node.js 24.22.1, Chromium 156.0.8078.79. Проверки выполнялись на реальном сервере приложения.

| Проверка | Результат |
|---|---|
| Данные мира | 20 комнат, 42 выхода; уникальные ID, принимающие точки, безопасные появления |
| Node-тесты | 36 тестов: контроллер, траектории, бой, ввод, граф, награды, смерть, сохранения, надписи на платформах, мобильная камера — пройдены |
| Production | Статическая сборка; запуск, движение, пауза, карта; отладочный API недоступен даже с `?debug=1` |
| Chromium-сценарий | Посещены 20 комнат; обе способности, оба сокращения, лифт туда/обратно и пауза внутри перехода |
| Учебный рывок | Пройден реальным вводом клавиатуры в браузере; обычный прыжок не пересекает разрыв в физическом тесте |
| Шахты | Реальный контроллер достигает верхних площадок P03/R04/R05 и пересекает крыши R06 |
| Смотритель | Победа 12 обычными ударами; флаг сохраняется, повторного противника нет; тестовый персонаж неуязвим |
| Возврат | R08 → R07 → R02 → вокзал → подъёмник → P07 → P02 → P03; позднее сердце собрано |
| Смерть/перезапуск | Возврат к месту отдыха R02; флаги, карта, способности, находки и настройки сохранены; здоровье с сердцем — 6 |
| Браузерные ошибки | Не зарегистрированы |
| Сенсорный интерфейс | 320×568, 390×844, 844×390; одновременное движение и прыжок через CDP, отпускание и отмена пальцев, поворот экрана, доступность настроек |
| Pages | Production локально запущен из `/Metroid/`: ресурсы, JSON, запуск и карта загружаются без ошибок; отладка закрыта |
| Производительность | 169 замеренных кадров в cloud Chromium; 2 врага, пополняемый лимит 160 частиц: 60 FPS в среднем, p95 17 мс, худший кадр 17.3 мс |

Сценарий использует подготовленные позиции возле объектов; это интеграционная проверка, а не непрерывное ручное прохождение. Боевой баланс и понятность маршрута новому игроку требуют плейтеста без неуязвимости. Замер в headless cloud не подтверждает производительность на минимальном пользовательском устройстве. Firefox, Safari и реальный мобильный геймплей отдельно не проверялись.

Повторить: `npm run validate`, `npm test`, `npm run build`, `npm run test:browser`, `npm run test:mobile`. Измерения контроллера: `npm run metrics`. Браузерные результаты и скриншоты — `artifacts/`; этот каталог не включается в git.
