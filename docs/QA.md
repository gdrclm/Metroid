Непрерывный маршрут управляется автоматической политикой, читающей состояние игры и выдающей только обычные действия. Он доказывает достижимость без тестовых перемещений, но не понятность пути незнакомому игроку. Отдельный интеграционный сценарий сохраняет подготовленные позиции для изолированных проверок.

## Оставшаяся ручная приёмка

Пункт 50 запроса не выполнен на физическом устройстве: такого телефона в cloud нет. На телефоне нужно пройти P05 (разрыв и возврат снизу), R05 (три ступени зацепа), R06 (верхний/нижний путь) и R07 (видимость подготовки обеих атак и повтор у лампы). Проверить портрет/альбом, два пальца, отмену касания и стабильность FPS. Также остаются слепой плейтест новым человеком и отдельная проверка Safari/Firefox.

## Повторить

```sh
npm run validate
npm test
npm run build
npm run test:production
npm run dev              # отдельный терминал, порт 3000
npm run test:browser
npm run test:mobile
npm run test:editor
npm run test:continuous
npm run test:journey
npm run metrics:shortcuts
```

Результаты JSON, ввод непрерывного Node-прогона и скриншоты находятся в игнорируемом `artifacts/`. Браузерные сценарии поддерживают `BASE_URL`. Редактор и статистика доступны только в dev-пульте; игровое сохранение и экспорт статистики остаются локальными.
