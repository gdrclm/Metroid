Для среза **Причал → Вокзал → Рабочие кварталы** эти три направления нужно проектировать вместе: звук сообщает о происходящем, частицы показывают физическое состояние места, окружение позволяет понять его историю.

Общая тема: **город держится на привычках людей и работе изношенных механизмов**. Внизу ощущаются вода и запустение, на Вокзале — ожидание, в жилых кварталах — сохранившаяся жизнь.

**1. Аудиодизайн**

Звуковой образ строится из пяти слоёв. Они не должны постоянно звучать одновременно.

| Слой | Содержание | Назначение |
|---|---|---|
| Общий фон | Вода, ветер, далёкий гул города | Объединяет мир |
| Звук помещения | Сквозняк склада, резонанс шахты, гул вокзала | Передаёт объём и материал |
| Локальные источники | Канат, печка, часы, труба, окно | Помогает исследовать |
| События | Приход лодки, запуск лифта, открытие решётки | Подтверждает изменения |
| Музыка | Редкие мотивы и переходы | Поддерживает эмоциональный ритм |

**Причал — вода, дерево, натяжение.**

- Низкие удары воды о сваи.
- Разная громкость плеска под открытым настилом и возле каменной стены.
- Скрип досок непосредственно под ногами.
- Поскрипывание натянутых канатов с нерегулярными интервалами.
- Редкий металлический удар о корпус судна.
- Ветер усиливается на открытых площадках.
- Далёкий городской колокол звучит приглушённо.

В `P01` после ухода лодки её звук постепенно исчезает. На несколько секунд музыка отсутствует: игрок остаётся с водой и собственными шагами.

**Вокзал — большой объём, металл, несбывшееся ожидание.**

- Длинный, но негромкий хвост шагов.
- Гул вентиляции и вибрация закрытых технических помещений.
- Редкое щёлканье табло.
- Звук часов, различимый только возле конкретной стены.
- Скрежет вагона или сцепки из недоступного тоннеля.
- Перед далёким механическим событием фон слегка затихает.
- В безопасной зоне слышны посуда, ткань и тихая человеческая деятельность.

В `V01` после остановки лифта сначала слышен общий объём зала, затем — отдельные источники. Это помогает почувствовать переход из тесной кабины в большое пространство.

**Рабочие кварталы — стены, трубы, люди за окнами.**

- Приглушённые разговоры без разборчивого постоянного текста.
- Посуда, шаги этажом выше, закрывающаяся ставня.
- Вода в водостоках.
- Стук труб с небольшими различиями между дворами.
- На крышах человеческие звуки становятся тише, ветер — заметнее.
- Возле кухни слышен чайник и работа печи.
- Ближе к арене появляется тяжёлый металлический ритм смотрителя.

**Музыкальная драматургия.**

| Эпизод | Музыкальное решение |
|---|---|
| Первые шаги | Короткий мотив, затем пауза |
| Первое место отдыха | Тот же мотив в более тёплом тембре |
| Получение рывка | Короткое расширение мотива, без длинной остановки игры |
| Открытие сокращения | Узнаваемая музыкальная фраза возвращения |
| Подъём к Вокзалу | Нарастание механического ритма, растворяющегося в акустике зала |
| Жилые кварталы | Осторожное появление живого инструмента |
| Перед смотрителем | Снижение фоновой насыщенности |
| После победы | Сначала тишина и механизм, затем музыка |
| Панорама R08 | Полное, но сдержанное проведение основной темы |

**Технические задачи для программиста:**

- [ ] Отдельные каналы: музыка, окружение, игровые действия, интерфейс.
- [ ] Локальные источники с затуханием по расстоянию.
- [ ] Плавный переход фоновых слоёв между комнатами.
- [ ] Приглушение источников за стенами и закрытыми дверями.
- [ ] Несколько вариантов шагов и ударов.
- [ ] Запрет на повтор одного варианта несколько раз подряд.
- [ ] Случайные интервалы для редких звуков окружения.
- [ ] Ограничение одновременных голосов.
- [ ] Приоритет предупреждений об атаке над фоновыми событиями.
- [ ] Сохранение состояния одноразовых звуковых событий.
- [ ] Отладочное отображение источников и радиусов слышимости.

**Критерий качества:** с закрытыми глазами можно приблизительно определить регион, отличить безопасное место от открытого пространства и услышать важное действие.

**2. Партикл-дизайн**

У частиц три функции: **объяснять среду, подчёркивать действие и направлять внимание**. Для каждой системы нужно заранее указать источник, направление движения и причину исчезновения.

| Эффект | Где используется | Поведение |
|---|---|---|
| Водяная пыль | Возле свай и ударов воды | Короткий выброс, быстрое оседание |
| Капли | Под трубами, мокрыми досками | Редкие, направленные вниз |
| Пыль в свете | Закрытые сухие помещения | Медленное движение только в освещённом объёме |
| Пар | Печь, клапан, прачечная | Выходит из конкретного отверстия, расширяется |
| Сажа | Возле работающего отопления | Небольшие тёмные частицы поднимаются вверх |
| Ржавчина и крошка | Запуск старого механизма | Короткая реакция на вибрацию |
| Волокна и сор | Крыши, бельевые дворы | Подхватываются порывами ветра |
| Искры | Повреждённый контакт или удар металла | Редкое локальное событие |
| След рывка | Движение героя | Показывает направление и скорость |
| Частицы удара | Бой | Передают материал и силу контакта |

**Причал.**

- Брызги появляются там, где вода ударяет в препятствие.
- С мокрых канатов падают редкие капли.
- При приземлении на старые доски вылетают щепки или пыль в зависимости от поверхности.
- Порыв ветра одновременно влияет на сор, ткань и след рывка.
- Под навесом количество дождевых капель уменьшается, но сохраняются стоки с края крыши.

**Вокзал.**

- Пыль заметна в отдельных полосах света.
- При запуске лифта с верхней балки осыпается крошка.
- Пар появляется возле работающих труб.
- При открытии давно закрытой решётки происходит один выразительный выброс пыли.
- В жилой части вокзала воздух визуально спокойнее.

**Рабочие кварталы.**

- Пар из прачечной стелется возле окон и вентиляционных отверстий.
- Из трубы кухни поднимается дым.
- На крышах ветер подхватывает небольшие бумажные обрывки.
- При опускании пожарной лестницы с неё осыпается ржавчина.
- После боя частицы быстро затухают, позволяя увидеть изменившееся пространство.

**Эффекты героя должны различать состояния.**

| Действие | Эффект | Что должен понять игрок |
|---|---|---|
| Обычное приземление | Небольшая реакция материала | Есть контакт с поверхностью |
| Сильное падение | Более широкий короткий выброс | Приземление было тяжёлым |
| Рывок | Вытянутый след и несколько направленных частиц | Герой резко ускорился |
| Восстановление рывка | Короткий акцент возле героя | Способность снова доступна |
| Зацеп | Небольшая крошка в точке контакта | Стена удерживает героя |
| Прыжок от стены | Короткий выброс от поверхности | Произошло отталкивание |
| Получение урона | Читаемая вспышка и направленный отклик | Герой повреждён |
| Успешный удар | Эффект в точке контакта | Атака достигла цели |

**Технические задачи:**

- [ ] Эмиттеры описываются данными комнаты.
- [ ] У эмиттера есть положение, направление, область, частота и время жизни частиц.
- [ ] Поддерживаются постоянный режим и разовый выброс.
- [ ] Эффекты привязываются к материалу поверхности.
- [ ] Ветер управляется общей системой, а не отдельной случайностью каждого эффекта.
- [ ] Частицы распределяются по слоям глубины.
- [ ] Эффекты вне видимой области ограничиваются.
- [ ] Есть общий бюджет и приоритет игровых эффектов над декоративными.
- [ ] Снижение качества уменьшает количество частиц без потери важных сигналов.
- [ ] Настройка уменьшения вспышек влияет на яркость и резкость эффектов.
- [ ] После загрузки завершённого события не повторяется выброс пыли или искр.

**Критерий качества:** частицы усиливают ощущение материала и движения, а силуэт героя, края платформ и подготовка атак остаются читаемыми.

**3. Нарративный левел-дизайн**

Каждая значимая комната должна отвечать на четыре вопроса:

1. Для чего это место использовали раньше?
2. Что здесь произошло?
3. Как его используют сейчас?
4. Что изменит присутствие игрока?

Историю лучше раскрывать последовательностью наблюдений. Например: сначала игрок видит следы воды на стенах, затем поднятые на балки вещи, потом — обустроенное жильё на бывшей технической площадке.

**Причал: люди постепенно отступали от воды.**

- На нижних стенах остаются отметки нескольких затоплений.
- Старые двери заколочены, новые входы прорублены выше.
- Бытовые вещи стоят на грузовых стеллажах.
- Настилы ремонтировали разными материалами.
- Канаты ведут к исчезнувшим или затонувшим объектам.
- В доме смотрителя сохраняется порядок, хотя вокруг всё разрушается.

Игровой маршрут поддерживает историю: герой постепенно поднимается от воды на верхние настилы.

**Вокзал: транспортное место стало поселением.**

- Билеты и расписания соседствуют с постелью и посудой.
- Перегородки сделаны из рекламных щитов.
- Платформенные указатели используются как адреса.
- Мастерская занимает бывшую кассу.
- Жители поддерживают часть инфраструктуры, необходимую для тепла и света.
- Закрытый тоннель остаётся предметом надежды или привычного ожидания.

Маршрут проходит от большого общественного зала к маленьким присвоенным людьми уголкам.

**Рабочие кварталы: жители выстроили собственные связи поверх сломанного города.**

- Мостик между окнами появился после разрушения лестницы.
- Общая кухня обслуживает несколько домов.
- Электричество проведено через соседнюю квартиру.
- На крыше есть обход опасной улицы.
- Пожарная лестница стала важным общим проходом.
- Смотритель контролирует механизм, от которого зависит доступ между дворами.

Игрок открывает сокращение, которое полезно и жителям. После этого можно показать небольшое изменение: человек перешёл на другую сторону, зажглось окно, возле кухни появились принесённые вещи.

**Ключевые сцены среза.**

| Эпизод | Что замечает игрок | Что делает | Что меняется |
|---|---|---|---|
| Прибытие | Лодка — последняя связь с прежним местом | Сходит на причал | Лодка уходит |
| Первый отдых | В комнате приготовлено место для гостя | Садится у тепла | Смотритель меняет занятие или коротко реагирует |
| Получение рывка | Предмет связан с краном и ветром | Осваивает движение | Пересекает видимый ранее разрыв |
| Открытие решётки | Узнаёт дом с обратной стороны | Поднимает решётку | Появляется короткая связь |
| Подъём | Видит недоступные этажи города | Запускает кабину | Раскрывается масштаб мира |
| Кухня | Замечает следы совместного быта | Останавливается | Получает повод подняться выше |
| Победа | Смотритель удерживал важные механизмы | Освобождает лестницу и мост | Район становится связнее |
| Панорама | Видит источники знакомых звуков | Поднимается на башню | Выбирает, какое направление интересует его дальше |

**Для каждой комнаты подготовить небольшую карточку:**

- **Прошлая функция:** например, склад соли.
- **Изменение:** помещение неоднократно затапливало.
- **Настоящая функция:** верхние балки используются как кладовая.
- **Главная улика:** вещи подняты выше линии воды.
- **Вторичная улика:** лестница сделана из крышек ящиков.
- **Игровое действие:** подняться в верхнюю нишу.
- **Награда:** предмет и новое понимание места.
- **Звуковой ориентир:** капли в металлическую ёмкость.
- **Эффект среды:** пыль наверху, сырость внизу.
- **Изменение после посещения:** открытый проход или перемещённый механизм.

**Задачи для программиста:**

- [ ] События при входе, приближении, взаимодействии и изменении флага.
- [ ] Одноразовые сцены с сохранением завершения.
- [ ] Варианты состояния комнаты до и после события.
- [ ] Простые фоновые занятия NPC.
- [ ] Изменение звука, света и частиц по состоянию мира.
- [ ] Возможность показать событие без отключения управления.
- [ ] Безопасное прерывание сцены выходом, смертью или закрытием игры.
- [ ] Связь одного события с несколькими последствиями: мост, звук, NPC, свет.
- [ ] Просмотр всех состояний комнаты в отладочном режиме.

**Первый комплект для реализации — четыре сцены:** уход лодки в `P01`, тёплый дом в `P02`, подъём в `P08→V01` и открытие пожарной лестницы в `R07→R02`. Для каждой одновременно сделать окружение, звук, частицы и изменение состояния. Это даст законченные примеры атмосферы, по которым можно оформлять остальные комнаты.
